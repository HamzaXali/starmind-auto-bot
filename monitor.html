ℹ️ What this dashboard can verify
This page reads public GitHub Actions run and job data. It can show workflow status and individual step status while GitHub reports them. It does not invent post counts, subscriber counts, image quality, or Telegram delivery confirmation. Those details need the bot workflow to publish explicit results. GitHub may rate-limit anonymous API requests; use the workflow link if data temporarily fails.
